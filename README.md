# 🎄 Christmas Bingo 聖誕賓果

派對用的賓果遊戲：Mac 大螢幕當開獎機，大家用手機玩賓果卡。

- **主持端**（`index.html`）：左邊是仿真賓果機（球在玻璃艙裡翻滾、出球、放大揭曉），右邊是 1–99 號碼牆。按「開球」或空白鍵開號，有音效和語音報號。
- **玩家端**（`card.html`）：掃主持畫面上的 QR Code 進來，系統自動發一張 5×5 隨機卡（中間是免費格）。點號碼就能圈起來，連成線會畫出線條，**兩條線過關**，畫面會顯示精確到毫秒的完成時間。

## 怎麼玩

1. Mac 用瀏覽器打開主持頁面，按 ⛶ 進入全螢幕。
2. 大家掃 QR Code，輸入名字，領卡。
3. 主持人按「開球」，大家自己在手機上圈號碼。
4. 先連成兩條線的人把過關畫面給主持人看，對照號碼牆核對。

## 小提醒

- 卡片存在手機裡，重新整理不會換卡。新的一局請按「換一張新卡」。
- 主持端開過的號碼也會保存，重開頁面不會遺失；按「↺ 重來」（按兩次確認）就能開始新的一局。
- 第一次按開球後瀏覽器才會允許播放聲音。
